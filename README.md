# CRUD Diario Django

## Descripción

Este proyecto es un CRUD de un diario hecho con Django.

## Funciones

- Ver las entradas
- Ver el detalle de una entrada
- Editar una entrada
- Eliminar una entrada

## Tecnologías

- Python
- Django
- HTML
- CSS
- SQLite

## Como ejecutar el proyecto

1. Descargar o clonar el proyecto.
2. Abrir la carpeta en la terminal.
3. Ejecutar:

python manage.py migrate

4. Ejecutar el servidor:

python manage.py runserver

5. Abrir en el navegador:

http://127.0.0.1:8000/diario/lista/

## Vistas utilizadas

- CreateView
- ListView
- DetailView
- UpdateView
- DeleteView
